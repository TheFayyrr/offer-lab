# Offer Lab｜高薪私企 vs 央国企综合待遇计算器

一个完全静态、移动端适配的中文 Offer 对比网页，适合用 GitHub Pages 发布。

## 功能

- 比较月固定工资、年度奖金、现金补贴、单位公积金、企业年金、其他福利。
- 计算年度可计价总包、税前现金性时薪、总包折算时薪。
- 交互式可视化、逐项对比明细。
- 浏览器本地自动保存（localStorage），导出 JSON 或 CSV。
- 不依赖第三方 JS、数据库、后端、API Key。

## GitHub Pages 发布（最简）

1. 在 GitHub 新建公开仓库，例如 `offer-lab`。
2. 将 `index.html` 和 `README.md` 上传到仓库根目录并提交。
3. 进入仓库 **Settings → Pages**。
4. 在 **Build and deployment** 下选择 **Deploy from a branch**，Branch 选择 `main`，Folder 选择 `/(root)`，点击 **Save**。
5. 等 GitHub Pages 部署完成后，网站通常位于 `https://你的用户名.github.io/offer-lab/`。

本地使用也很简单：直接双击 `index.html`。

## 重要口径

- “年度可计价总包”＝固定工资 × 12 + 预计奖金 + 单位公积金年缴存 + 单位企业年金年缴存 + 现金补贴 + 非现金福利估值。
- 不估算个税或个人扣款，因此**不是到手收入**。
- 不计入单位社保缴费；它是保障成本，并非员工可支配现金。
- 示例仅供理解；填入实际缴存基数和比例，且应遵守当地政策及上限。
- 企业年金、住房公积金及其他福利可能有领取限制；未兑现的股票激励建议单独评估。
- “央企正式编制”通常不是事业单位编制，实际用工性质以合同为准。

## 隐私

输入内容只保存在你当前设备的浏览器中，不会主动发往服务器。使用共享电脑时请注意浏览器数据留存。
